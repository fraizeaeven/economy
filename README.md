# Malaysia Economy Status Tracker

An analytical dashboard and intelligence platform tracking key economic indicators, fiscal policies, and macroeconomic trends for Malaysia.

## Key Features
- **Macroeconomic Dashboard**: Real-time tracking of GDP growth, inflation rate (CPI), unemployment, and trade balance.
- **Fiscal & Monetary Policy Logs**: Insights on Bank Negara Malaysia (BNM) OPR decisions and government budget allocations.
- **Currency & Market Analytics**: Visualization of Ringgit (MYR) performance against major global currencies.
- **Sectoral Analysis**: Deep-dives into manufacturing, services, agriculture, and digital economy sectors.

## Tech Stack
- **Frontend**: Next.js (App Router) + Tailwind CSS + Recharts/Tremor
- **Backend**: FastAPI (Python) for macroeconomic data pipeline & API
- **Database**: PostgreSQL / SQLite (Development)

## Getting Started
1. Clone the repository.
2. Install dependencies for frontend and backend.
3. Run the development servers.
